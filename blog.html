Der erste Meilenstein: Ubuntu Server läuft

Ubuntu Server 26.04 LTS installiert, ein hartnäckiges Netzwerkproblem gelöst, DHCP erfolgreich eingerichtet (192.168.1.102), Internetzugriff hergestellt, System aktualisiert und der neue Kernel 7.0.0-22-generic aktiviert. Der SSH-Dienst wurde eingerichtet. Der Fernzugriff wurde anschließend über die aktuelle Netzwerktopologie weitergeführt: Der Server hängt per LAN am Netzwerk, der Windows-PC nutzt einen USB-WLAN-Adapter. Dieser Beitrag hält den damaligen Zwischenstand fest.
